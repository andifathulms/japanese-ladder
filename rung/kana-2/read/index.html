Lihat terjemahan

Saya Rina. Saya orang Indonesia. Setiap hari saya pergi ke kantor naik kereta. Pagi hari saya membeli roti dan kopi di minimarket. Siang hari saya makan kari di restoran. Malam hari saya menonton televisi. Televisi Jepang agak sulit. Tapi menyenangkan.
